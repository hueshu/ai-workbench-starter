# AI 工作台起步（ai-workbench-starter）

**中文** ｜ [English](README.en.md)

AI 窗口开多了，谁在干什么、干到哪了，全靠脑子记？

这是一个给 AI 读的 skill。让它在你电脑的一个文件夹里搭起五样东西，以后换哪个窗口、哪个 AI 来，都能接着干：

| 五样 | 解决什么 |
| --- | --- |
| 收件箱 | AI 老来问你。只留两种：要你动手的、要你拍板的 |
| 派活 | 同一段话一个个窗口去贴。每件事一张派活单，写清怎么算做完 |
| 验收 | AI 说「做完了」其实没做成。换个新窗口看证据，没证据算没做完 |
| 夜班 | 你睡了活就停。能推的自己推，推不动的写进收件箱 |
| 交接 | 窗口一长就忘。每件事留一页，谁来先读它 |

每天早上只看一页 `首页.md`。

## 要有什么

一个能读写你电脑本地文件的 AI。网页里聊天的那种不行。全是文本文件，不装东西，不联网。

## 怎么用

1. 下载：点右上角 **Code → Download ZIP**，解压。
2. 对你的 AI 说（路径换成你的）：
   > 先读 `ai-workbench-starter/SKILL.md`，照它来。帮我搭一个工作台。
3. 搭好后派活：
   > 派活：把下载文件夹里的文件按类型归类，先出清单，不要移动文件。
4. 换新窗口：
   > 先读 `AI工作台/规则.md` 和 `ai-workbench-starter/SKILL.md`，验收刚才那张派活单。
5. 第二天：
   > 早上看一页。

英文版在 `ai-workbench-starter-en/`，内容一样，建出来的文件夹叫 `ai-workbench`。两版选一个用。

会用技能目录的，把 `ai-workbench-starter` 文件夹放进去即可（这条路还没逐个客户端试过）。

## 试过哪些

2026-11-23 在豆包工作、WorkBuddy 里各跑通一遍（搭、派活、验收、试问、早上看一页），Gemini 命令行另跑过夜班和接手；之后只把模板改成英文文件名，从这里下载 ZIP 用 Gemini 照上面的话重走过搭建、派活、验收。每项只跑了一两次，用的是示例文件。别的 AI 能读写本地文件理论上也行，没试过。

## 它不做什么

- 不会自己启动，要你说一声，或用客户端的定时任务。
- 不会自动往别的窗口发消息，新窗口读了文件才算收到。
- 花钱、对外发、删东西、登录密码，一律先停下等你。这是写给 AI 的规矩，不是系统级的锁，重要文件自己先备份。
